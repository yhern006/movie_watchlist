# Movie Watchlist

## About
Solo Project from Scrimba's APIs and Async JS course in the Full Stack Developer Path.

This project is meant to get practice with the OMDb API, local storage, CSS and JavaScript.

## Project Requirements
- [Completed] Follow Figma Design
- [Completed] Have search page call to OMDb API with the movie title searched for then display results
- [Completed] 'Add to Watchlist' Button saves data to local storage
- [Completed] Watchlist.html loads and displays data from local storage
